How it works

  1. Add a password-protected PDF.
  2. Enter its password.
  3. Click "Unlock & Download" to get a copy with the password removed, done entirely in your browser.

Only use this on PDFs you're allowed to unlock. Need to add a password instead? Use Protect PDF.
