How it works

  1. Add a PDF that isn't already password protected.
  2. Choose a password, anyone opening the file will need to enter it.
  3. Optionally set a separate owner password and turn off printing, copying, editing or form filling.
  4. Click "Protect & Download" to get your encrypted PDF, AES-256 encryption, done entirely in your browser.

Got a protected PDF and need the password removed? Use Unlock PDF instead.
