Private mode is off. Every page except Contact loads only this site's own files. The Contact page also loads Web3Forms and hCaptcha, described below.

The shield button at the top of every page turns Private mode on for this browser. With it on, the contact form is hidden, Web3Forms and hCaptcha are never contacted, and links send no referrer. It is remembered in this browser only, as one small note in local storage, and can be turned off the same way.
