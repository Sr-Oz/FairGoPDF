How it works

  1. Pick a board size (or set a custom width/height) and a background colour.
  2. Add photos, each one drops onto the board as its own box.
  3. Click a photo to select it: drag to move, a corner dot to resize, the round handle above it to rotate.
  4. Use "Bring to front" / "Send to back" to control which photo overlaps which.
  5. Click "Save & Download" to export the board as one image.

There's no automatic grid or layout here, every photo is placed and sized by hand, overlapping and rotation are the whole point. Changing the board size afterwards doesn't rescale photos you've already placed, drag them back into place if you switch sizes partway through.
