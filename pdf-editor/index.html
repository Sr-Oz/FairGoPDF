How it works

  1. Add a PDF, every page renders below.
  2. Click a page to select it, then "Add Text" or "Add Image" to drop a box onto it.
  3. Drag a box to reposition it, drag a corner dot to resize (text resizes its font size, images keep their aspect ratio).
  4. Click a selected text box again to edit its words, use the toolbar for font, size, colour, bold and italic.
  5. Click "Save & Download" when you're done, on every page.

This adds genuine, selectable text and real embedded images baked into the PDF, using standard Helvetica/Times/Courier fonts, it isn't a scanned/flattened image. Need a signature instead? Use Sign PDF.
