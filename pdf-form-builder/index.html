How it works

  1. Add a PDF and pick a page from the thumbnails.
  2. Choose a field type: text field, checkbox, radio button or dropdown.
  3. Click and drag on the preview to place it, then name it and set any options.
  4. For radio buttons, give every option in the same question the same group name.
  5. Repeat on any other pages, a dot marks pages with at least one field.
  6. Click "Build Form & Download" — open the result in any PDF reader that supports forms to fill it in.

Fields are added as real, interactive AcroForm fields, the same kind produced by Acrobat or any other form-authoring tool, not flattened images. Anyone opening the file in Adobe Reader, Preview, or most browsers can click straight in and type.
