Posterise PDF

Tile a PDF page across multiple printable sheets so you can print it oversized and tape it together. Processed locally, nothing is uploaded.

How it works

  1. Add a PDF file.
  2. Pick how large a poster you want, 2×2, 3×3 or 4×4 sheets.
  3. Click "Posterise & Download", print every sheet at 100%, trim the margins and tape them together.

Every page in the file is posterised. If your PDF has several pages, save the specific page you want first with Split PDF.
