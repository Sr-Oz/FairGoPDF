Add a Stamp to a PDF

Place a logo, "APPROVED" graphic or any image onto a PDF, on one page, a range, or every page. Processed locally, nothing is uploaded.

Leave "Pages" blank to stamp every page. Use a single page number, a comma-separated list, or a range like 1,3,5-8.

How it works

  1. Add a PDF file and a stamp image (a logo, signature graphic, "APPROVED" stamp, whatever you need).
  2. Choose which pages get stamped, where on the page, how big, how see-through, and any rotation.
  3. Click "Add Stamp" to download the stamped PDF.

Use a PNG with a transparent background for the cleanest result, a solid rectangle will show through with a JPG. This stamps a static image, it isn't a cryptographically verified e-signature.
