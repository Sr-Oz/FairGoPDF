    How it works

    1. Add two or more photos, drag the ↑ / ↓ buttons to set the order.
    2. Pick a layout: a square-cell grid, a horizontal row, or a vertical column.
    3. Adjust size, spacing, background colour and output format.
    4. Click "Create Collage" to download the combined image.

    Grid mode crops each photo to fill a square cell, the classic collage look. Row and column mode scale every photo to a common height or width and keep the full image, no cropping, more like a photo strip.

    Proudly built for straightforward document management, 100% client-side, nothing is ever uploaded.
