How it works

  1. Add a PDF file.
  2. Fill in any of the six zones you need, left, centre and right, for the header and footer.
  3. Click "Add Header & Footer" to download the result.

Every zone is applied to every page. This is different from Add Page Numbers, which places a single number in one spot, and from Watermark PDF, which stamps one centred watermark, this tool is built for running titles, document IDs, confidentiality notices and page numbers all at once.

Proudly built for straightforward document management, 100% client-side, nothing is ever uploaded.
