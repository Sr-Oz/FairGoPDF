How it works

  1. Type or paste any text, or drop in a PDF, Word (.docx) or .txt file.
  2. Every count updates live.
  3. Reading time is estimated at 200 words per minute.

Everything runs locally, nothing you type or upload is ever transmitted anywhere. PDF text extraction is best-effort, it won't pull text from a scanned image without OCR.

Proudly built for straightforward document management, 100% client-side, nothing is ever uploaded.
