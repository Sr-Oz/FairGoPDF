Crop PDF Pages

Drag the corners to select a crop area on the first page, it's applied proportionally to every page. Processed locally.

crop
Drop your PDF here, easy as.
One PDF file

This crop is applied as the same proportion of each page, if your PDF's pages are different sizes, the crop area on each page will scale to match. Rows and columns of margin trimmed from the first page are trimmed the same way from every page.

How it works

  1. Add a PDF file, its first page renders as a preview.
  2. Drag the corner handles to select the area you want to keep.
  3. Click "Crop PDF" to download the result.
