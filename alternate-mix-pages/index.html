Alternate & Mix PDF Pages

Interleave two PDFs page by page, the classic fix for a double-sided document scanned as two single-sided passes. Processed locally, nothing is uploaded.

Turn this on if File B was scanned back-to-front, common when you flip the whole stack over for the second pass instead of feeding it page by page.

How it works

  1. Add File A (the fronts) and File B (the backs).
  2. Turn on "Reverse File B" if the second pass came out back-to-front.
  3. Click "Interleave & Download", pages come out as A1, B1, A2, B2, and so on.

If the two files have different page counts, the extra pages from the longer one are simply added at the end.

Proudly built for straightforward document management, 100% client-side, nothing is ever uploaded.
