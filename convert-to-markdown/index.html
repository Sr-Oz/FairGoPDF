How it works

  1. Add a PDF, Word (.docx) or HTML file, or paste HTML/rich text directly.
  2. The content is converted to Markdown right there in your browser.
  3. Copy it directly, or download the whole thing as a .md file.

PDF conversion pulls out the text and reconstructs paragraphs, it's best-effort since PDFs don't store real document structure, so headings and lists may need a touch-up. Word and HTML conversion is far more reliable, since those formats keep their actual formatting.
