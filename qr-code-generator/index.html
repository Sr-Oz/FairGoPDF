How it works

  1. Type or paste any text or URL, the QR code updates instantly.
  2. Adjust the error correction level and size if you need to.
  3. Download as a PNG (for most uses) or SVG (for crisp printing at any size).

Higher error correction levels make the code more resistant to damage or dirt, at the cost of a denser pattern, useful if you're printing it small or somewhere it might get scuffed. Everything is generated locally, the text you enter is never transmitted anywhere.

Proudly built for straightforward document management, 100% client-side, nothing is ever uploaded.
