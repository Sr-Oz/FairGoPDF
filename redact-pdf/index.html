How it works

  1. Add a PDF and pick a page from the thumbnails.
  2. Click and drag on the preview to draw one or more boxes over anything sensitive.
  3. Repeat on any other pages that need it, a red dot marks pages with at least one box.
  4. Click "Redact & Download."

Why this is a real redaction, not just a black box: a lot of "redaction" tools just draw a black rectangle on top of the page, the text underneath is still there in the file and can be selected, copied, or recovered, this has caused real, public leaks. This tool takes a safer approach: any page you mark gets rasterised, turned into a flat picture with the black boxes baked in, before being placed back in the PDF. There's no text layer left on that page for anything to extract. The trade-off is that a redacted page becomes an image, so its text is no longer selectable or searchable, and the file gets a bit larger. Pages with no marks are left completely untouched.

Proudly built for straightforward document management, 100% client-side, nothing is ever uploaded.
