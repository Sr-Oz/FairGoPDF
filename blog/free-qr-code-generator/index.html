How to make a free QR code (no app, no sign-up)

Published 20 August 2026 · 4 min read

A surprising number of "free" QR code generators quietly route your code through their own shortened URL. That's how they later show you analytics, and it's also how a code printed on a flyer or menu can stop working years later if the company shuts the service down. A QR code generated locally, encoding your text or URL directly, doesn't have that failure point.

Step by step

  1. Open QR Code Generator and type or paste any text or URL, the code updates instantly as you type.
  2. Adjust the error correction level and module size if needed.
  3. Download as PNG for most uses, or SVG if you need it to scale to any size without blurring, useful for large prints like posters or banners.

A few practical tips

  • Higher error correction means a more damage-resistant code, at the cost of a denser pattern. Use "High" if the code will be printed small, laminated, or placed somewhere it might get scuffed or partially covered.
  • Always test-scan before printing at scale. Print or display a copy and scan it with a phone camera first, especially for small sizes or unusual materials.
  • Shorter text produces a simpler, more scannable code. A short URL scans more reliably at small sizes than a long one packed with tracking parameters.
